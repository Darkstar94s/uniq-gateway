## 1. حماية الملكية الفكرية وسلسلة التصنيع [مؤجل لمرحلة الإنتاج - TODO]

### أ. استراتيجية حماية الكود (Binary Compilation & Golden Image):
1. **تجميع الكود وعدم تسليم السورس كود للمصنع**:
   * تجميع كود البايثون إلى ملفات تنفيذية مشفرة عبر **Cython / PyInstaller** لمنع سحب الكود المصدري.
2. **صورة النظام المشفرة (Encrypted Golden OS Image)**:
   * إنشاء صورة نظام كاملة موحدة بنظام ملفات للقراءة فقط (**OverlayFS Read-Only**) لضمان استقرار النظام ومقاومته للتلف.
   * تشفير الذاكرة وربطها بالرقم التسلسلي الفريد للمعالج (CPU Serial / eFuse OTP).

### ب. محطة البرمجة المصنعية المؤتمتة (Factory Provisioning Tool):
* جهاز فحص (Test Jig) يشغل سكربت آلي:
  1. يولد تلقائياً **Serial Number** فريد بتسلسل محدد (مثال: `UNIQ-HUB-26A-0001`).
  2. يولد عشوائياً **رمز PIN فريد** من 6 أرقام.
  3. يولد شهادة أمان مشفرة (X.509 Certificate).
  4. يسجل الجهاز في سحابة UNIQ ويطبع ملصق الـ QR تلقائياً.

## 2. الدعم الفني وبروتوكول إعادة ضبط المصنع (Factory Reset Protocol)

### أ. زر إعادة الضبط الفيزيائي (Physical Smart Reset Button):
1. **الضغط لمدة 5 إلى 10 ثوانٍ (Network Reset - وميض أزرق)**:
   * مسح إعدادات شبكة الواي فاي فقط لإعادة ربطه بشبكة جديدة دون حذف الأجهزة.
2. **الضغط لمدة 20 إلى 30 ثانية (Full Factory Reset - وميض أحمر سريع)**:
   * مسح ذاكرة الأجهزة والملكية بالكامل وإعادة الـ PIN إلى الرمز المصنعي الأصلي.

### ب. أدوات الدعم الفني عن بُعد لفريق UNIQ (Remote Diagnostic Tunnel):
* **نفق صيانة مؤقت ومشفر عند الطلب**: يفتحه الموزع لمدة محددة عند موافقة العميل من التطبيق لفحص السجلات وتشخيص الأعطال دون فتح أي منافذ دائمة للإنترنت.

## 3. تجربة المستخدم وضبط الهاتف ونوعا المستخدمين (App Onboarding & RBAC)

### أ. خطوات الإعداد لأول مرة عبر تطبيق الجوال:
```
1. تشغيل الموزع في الكهرباء 
      ▼
2. بث إشارة إعداد (Bluetooth BLE أو شبكة مؤقتة UNIQ-Hub-XXXX)
      ▼
3. فتح تطبيق UNIQ ➔ اختيار "إضافة موزع" ➔ اكتشاف فوري عبر البلوتوث
      ▼
4. إرسال بيانات واي فاي المنزل للموزع عبر البلوتوث
      ▼
5. مسح كود الـ QR ورمز الـ PIN المطبوع على ظهر الجهاز ➔ نقل الملكية لحساب العميل
```

### ب. نوعا المستخدمين وصلاحياتهم (Role-Based Access Control):
1. **المالك الرئيسي (Owner)**: يمتلك أصل المنزل، صلاحية إضافة وحذف الأجهزة، دعوة أفراد العائلة، وإدارة الغرف والموزع.
2. **المستخدم العادي (Member)**: يتحكم فقط بالأجهزة المصرحة له (مثلاً: غرفة نومه، الصالة)، ولا يرى إعدادات الموزع الحساسة ولا يستطيع عمل Reset.

## 4. المراجعة الأمنية الشاملة وتحصين النظام (Security Hardening)

| نطاق التهديد | الخطر المحتمل | الحل المعتمد في UNIQ Hub |
| :--- | :--- | :--- |
| **الشبكة المحلية (LAN)** | محاولة اختراق الواجهة المحلية (Port 8282) | إغلاق المنفذ بـ PIN مشفر + حظر الآيبي بعد 5 محاولات خاطئة (Rate Limiting). |
| **سرقة العتاد (Hardware) [TODO]** | سحب بطاقة الذاكرة وقراءة الكود | تشفير ملفات التخزين بـ AES-256، وقفل منافذ UART المصنعية. |
| **الاتصال السحابي (Cloud)** | هجمات التنصت (Man-In-The-Middle) | اتصال مشفر بـ TLS 1.3 مع فحص الشهادة (Certificate Pinning). |
| **تحديثات النظام (OTA)** | رفع تحديث خبيث أو معطوب | توقيع كافة التحديثات بمفتاح رقمي خاص بـ UNIQ (RSA Signature). |
| **خصوصية بيانات المنزل** | تسريب بيانات الحساسات | تخزين مشفر، وتفضيل المعالجة المحلية أولاً (Local First). |

## 5. هندسة تحديثات الموزع عند نزول إصدار جديد (Over-The-Air OTA Updates)

### أ. فئات التحديثات الثلاثة ومصادرها (The 3 Release Tiers):
1. **تحديثات برمجيات وموصلات UNIQ (Application Software OTA)**:
   * تشمل موصل Matter، دعم أجهزة جديدة، وتحسينات الواجهة المحلية.
   * حزمة خفيفة تنزل بالخلفية وتثبت خلال **5 ثوانٍ فقط (Hot-Reload)** دون انقطاع أجهزة المنزل.
2. **تحديث إصدار ThingsBoard الرسمي من المنبع (Upstream Gateway Core)**:
   * بفضل معمارية **Zero-Touch Upstream**، يتم سحب ودمج إصدارات ThingsBoard الرسمية عبر Git بنقرة زر وبدون أي تعارض في الأكواد.
3. **تحديث الفيرموير ونظام التشغيل الكامل (Firmware / OS OTA) [TODO لمرحلة العتاد النهائي]**:
   * ترقية نواة لينكس وتعريفات العتاد عبر نظام التقسيم المزدوج (A/B Partitioning) مع خاصية التراجع التلقائي (Auto-Rollback) لمنع تلف الجهاز (0% Brick Rate).

### ب. خطة الطرح التدريجي (Canary Deployment):
* توزيع التحديث على 3 مراحل:
  1. أجهزة المهندسين الداخلية (1%).
  2. عملاء بيتا المتطوعين (10%).
  3. الإطلاق العام لكافة العملاء (100%) مع توفير زر الإيقاف الطارئ (Kill Switch).

### ج. تجربة المستخدم عبر التطبيق:
* إشعار بتوفر التحديث وسجل التغييرات مع زر "تحديث الآن" أو "تحديث تلقائي ليلاً (3:00 فجراً)".
* مؤشر ضوئي في الموزع ينبض باللون البنفسجي أثناء التثبيت ثم يعود للأخضر الطبيعي بعد اكتمال التحديث بنجاح.

## 6. ما الذي يمكن عمله بدون الموزع الذكي؟ (With vs Without Hub)

| الخاصية | بدون الموزع (Direct Wi-Fi / Cloud Only) | بوجود موزع UNIQ Hub |
| :--- | :---: | :---: |
| **مفاتيح ومقابس Wi-Fi** | ✅ تعمل عبر السحابة مباشرة | ✅ تعمل بسلاسة محلياً وسحابياً |
| **العمل عند انقطاع الإنترنت** | ❌ تتوقف الأوامر الذكية والمشاهد | ✅ تعمل محلياً بكفاءة 100% دون إنترنت |
| **أجهزة وحساسات Zigbee** | ❌ غير مدعومة | ✅ مدعومة بالكامل وتوفر بطارية لسنوات |
| **أجهزة Matter over Thread** | ❌ غير مدعومة | ✅ مدعومة عبر الـ Hub |
| **جسور Matter Bridges (SONOFF وغيرها)**| ❌ غير مدعومة | ✅ مدعومة وتظهر كل حساس كجهاز مستقل |
| **زمن الاستجابة (Latency)** | 200 - 500ms (ذهاباً وإياباً للسحابة) | 5 - 20ms (استجابة فورية فائقة السرعة) |

## 7. إجراءات وفلسفة التهيئة التلقائية الحديثة (Smart Multi-Home Provisioning)

* **إنشاء المنزل المرن**: إدخال اسم المساحة واختيار الغرف بنقرة واحدة عند التسجيل.
* **التبديل بين المنازل (Multi-Home)**: التحكم في الشقة، الفيلا، والمكتب من حساب واحد.
* **المشاركة الذكية**: مشاركة المنزل أو غرف محددة مع أفراد الأسرة بكود دعوة سريع.

---

## 8. الدعم الشامل لكافة فئات أجهزة المنزل الذكي (Full Smart Home Clusters)

* **الإنارة**: تشغيل/إطفاء، ديمر سطوع، وألوان RGB.
* **المقابس والقواطع**: تحكم كامل وقراءة لحظية لاستهلاك الطاقة (W, kWh, V, A).
* **التكييف ووحدات IR**: مكيفات ذكية وريموتات تحكم بالأجهزة المنزلية.
* **الأمان والحساسات**: حرارة، رطوبة، حركة، حساسات أبواب، وتسريب مياه.
* **المداخل والستائر**: أقفال ذكية (DoorLock) ومواتير ستائر وبوابات كراج.
* **دعم أي جسر مفتوح عالمياً**: SONOFF, Tuya, Aqara, Philips Hue, IKEA Dirigera.

## 9. روتين فريق UNIQ للتشغيل والدعم الفني مابعد البيع

1. **إدارة المخزون والتفعيل (Device Lifecycle)**: تتبع حالة كل موزع (في المستودع ➔ تم الشراء ➔ نشط).
2. **المراقبة اللحظية لصحة الأسطول (Fleet Telemetry)**: متابعة حرارة الموزعات، استهلاك الذاكرة، وجودة الواي فاي.
3. **بوابة الدعم الفني السريع**: فحص السجلات وحل المشاكل التقنية بطلب نفق تشخيص آمن من العميل.
